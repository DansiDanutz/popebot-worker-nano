# popebot-worker-nano

This repository is an intentional non-executable placeholder for the Nano
PopeBot worker identity. It reserves the repository name and provides a stable
link for fleet inventory; it does not contain, deploy, or operate a worker.

## Contract

- No application source, package manifest, lockfile, container definition,
  deployment configuration, credentials, or generated runtime state belongs
  here.
- No GitHub, Vercel, or other hosted deployment is required for this contract.
- Runtime work must be created in a separately named repository with its own
  audit, protected review, tests, dependency evidence, and deployment proof.
- Adding executable behavior changes this repository's contract and requires a
  fresh RepoAudit classification before merge.

RepoAudit tracking: [repoaudit#387](https://github.com/DansiDanutz/repoaudit/issues/387).
